The pieces

One picture of the whole thing.

The diagram from the architecture doc. Its sources are in docs/architecture/, written by generate.py, with five more pages: the system on GKE, every kernel type, every console module, one run call by call, and the state machines.

  • Catalog repositoryTeams' products: product.yaml, Dockerfile, tests. CI builds, scans, signs and releases.
  • RegistryProduct images and the signed catalog-release every console pulls.
  • consoleSigns people and bots in and authorizes every request. Its own Postgres.
  • kernel-apiValidates and stores DAGs. Answers only the console.
  • kernel-schedulerClaims ready steps, starts and watches one Job per attempt.
  • Team namespacesWhere steps run, labelled vennir/team=true. Admission policies check every Job.

Hands-on labs

Exercises to do in order, each with its goal, time, cost and checks: two free on your laptop, then a GKE install creating resources on every cloud.

  • Lab 1: Vennir on your laptop Install on kind, run a DAG, publish the samples, run a template and a cart, and delete what a run made. Free, about 45 minutes. console/docs/lab-1-laptop
  • Lab 2: your first product A catalog of your own, a product from the starter, tests run as CI runs them, a secret, and errors that explain themselves. Free. console/docs/lab-2-first-product
  • Lab 3: Vennir on GKE, with a catalog A released Vennir on GKE Autopilot at the smallest size, priced before it's made, and a catalog whose CI publishes with no stored key. Billed. console/docs/lab-3-gke
  • Lab 4: Google Cloud projects from Vennir Projects made under a folder of their own, a Cloud Run service with grants inherited from the folder, and deletes through Vennir. Billed. console/docs/lab-4-gcp-projects
  • Lab 5: AWS from a GKE install An S3 bucket and an ECS Express service, each product as an IAM role of its own by web identity, no AWS cluster and no key. Billed. console/docs/lab-5-aws-from-gke
  • Lab 6: Azure from a GKE install A resource group, a Container App and PostgreSQL, each product a managed identity of its own, and a Key Vault secret synced. Billed. console/docs/lab-6-azure-from-gke
  • Lab 7: APIs on every cloud, through the gateway The gateway on the internet, serving a backend on AWS and one on Azure behind Entra sign-in, and every way around it refused. Billed. console/docs/lab-7-apis-across-clouds
